# Domain Model (Task 2)

## Value Objects

| Value Object        | Purpose                                      | Key Rules                                      |
|---------------------|----------------------------------------------|------------------------------------------------|
| BodyCondition       | شرایط بدنه + قطعات رنگ‌شده                   | اگر رنگ شده باشد باید قطعات مشخص شوند         |
| ChassisCondition    | وضعیت شاسی                                   | اگر ضربه خورده باشد محل ضربه الزامی است       |
| EngineCondition     | وضعیت موتور                                  | سه حالت ساده                                   |
| GearboxCondition    | وضعیت گیربکس                                 | سه حالت ساده                                   |
| PriceOffer          | قیمت + نوع فروش                              | معاوضه و شرایطی نیاز به جزئیات دارند           |
| DocumentStatus      | وضعیت سند و مدارک                            | مشکل‌دار نیاز به توضیح دارد                    |
| OwnerContact        | نام + موبایل + قابلیت مخفی کردن              | فرمت موبایل 09xxxxxxxxx                        |

## Entities

- **User**: مالک یا ادمین (ورود فقط با OTP موبایل)
- **Car**: خودرو کامل با تمام Value Objectها

## Repository Interfaces

- `ICarRepository` – CRUD + فیلتر پیشرفته + soft delete
- `IUserRepository` – مدیریت کاربران

## Prisma Mapping

- Value Objectهای پیچیده به صورت ترکیب enum + آرایه رشته‌ای + فیلد توضیحات ذخیره می‌شوند.
- این کار هم type-safety در دامنه را حفظ می‌کند و هم فیلتر و ایندکس در دیتابیس را ممکن می‌سازد.
- `priceAmount` به صورت `BigInt` ذخیره می‌شود (مبالغ بزرگ تومان).

## Indexes

ایندکس‌های ترکیبی برای فیلترهای پرتکرار (برند+مدل+سال، فعال بودن+برند+قیمت) اضافه شده‌اند.
