# Public Cars Listing (Task 5)

## Features

- صفحه لیست عمومی `/cars` کاملاً موبایل‌فرست
- جستجوی متنی زنده (برند، مدل، تیپ، رنگ)
- فیلترهای پیشرفته جمع‌شونده:
  - برند، مدل
  - بازه سال ساخت
  - بازه قیمت
- Skeleton loading
- کارت‌های فشرده و خوانا برای موبایل
- صفحه جزئیات `/cars/[id]` با:
  - مشخصات کامل
  - دکمه تماس مستقیم (tel:)
  - سلب مسئولیت
  - Sticky CTA تماس

## SEO

- Metadata کامل در layout اصلی و layout لیست خودروها
- Open Graph پایه
- robots index/follow
- viewport بهینه برای موبایل

## API

- پارامتر `search` به endpoint عمومی اضافه شد
- مرتب‌سازی بر اساس جدیدترین
